## 🛡️ Built-in Automatic Fallback Mechanism

The website utilizes `src/components/ImageWithFallback.jsx`.

- **Primary Source:** Checks the local image file in `src/assets/images/`.
- **Automatic Fallback:** If the file is missing, empty, or fails to load, it automatically switches to a high-resolution, visually matching fallback without showing broken image icons or causing layout shifts.
- **Aspect Ratio & Fit:** `object-cover` and responsive aspect ratios ensure flawless rendering on mobile, tablet, and desktop screens.
